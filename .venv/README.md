# Microeconomic Supply–Demand Simulator

Interactive web application modeling supply-demand equilibrium, tax incidence, welfare analysis, and deadweight loss using Python and Streamlit.

## Features
- Supply & demand equilibrium calculation
- Per-unit tax analysis
- Consumer & producer surplus
- Deadweight loss visualization
- Tax revenue & tax incidence breakdown

## Run Locally

```bash
pip install -r requirements.txt
streamlit run src/app.py
